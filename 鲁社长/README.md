用途：持续整理用户指定的鲁社长视频或提供的文稿，提取所有人名，并积累中共官场人物关系线索。

## 打开交互网页

[已发布站点：鲁社长大老王宇宙](https://ccpedia.liugongming.chatgpt.site)（沿用现有站点访问范围）。新增正圆布局、点击人物移至圆心、直接关联高亮及图形方案参考。

[人物谱系 HTML 测试版](关系图谱/index.html)：可双击离线打开，无需安装。搜索真实姓名或已核对别名，悬停查看背景，点击查看档案；拖动时间轴或输入日期可回看事件与关系。

当前：103 位人物、86 条关系、24 条事件；最新视频55条细节、59位人物，新增55位实名人物。最新一期使用同题播客分析与原视频章节定位，未逐句校时。头像缺失和身份待确认情况在网页说明中标记。

更新命令：先运行 `数据库/export.py`，再运行 `关系图谱/build.py`。SQLite 为唯一人物数据来源；不要直接修改生成的 index.html。

新增视频必须先完整阅读[工作流](../工作流.md)。

## 后续整理约定

1. 每份材料以视频 ID 命名，记录来源链接、标题、整理日期及实际读取范围。
2. 提取节目具名公众人物；排除外国国家元首与仅观众账号；创作者公开笔名可保留。
3. 尽量保留时间戳。没有时间戳时使用段落编号，不补造时间。
4. 人物关系分别标明主讲人观点、被转述的观众说法、推断及独立核实结果；不将同段出现当作存在关系。
5. 对争议信息分别记录各方说法，不将传闻、预测或主讲人的自述当作确定事实。
6. 先保存逐段Markdown（包含细节事件、推测、匿名称谓及时间码），再更新SQLite与累计索引；有依据才跨视频合并昵称与实名。
7. 从第三方视频读取的材料保存人名索引与概括性分析，不全文归档。用户直接提供的字幕或文稿可保存到“用户提供文稿”目录，保留原始版本，另存整理结果。

2026-09-23：增加三层亲属展开及资料占位；新增齐心档案及4条公开资料支持的亲属关系。层数是关系路径步数，含兄弟姐妹与姻亲。

默认按节目叙述浏览；“显示核对标记”可恢复细项状态。原始证据状态、来源和时间模型保持在SQLite中。
