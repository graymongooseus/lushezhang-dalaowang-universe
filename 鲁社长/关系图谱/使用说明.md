# 人物谱系 HTML 测试版

双击本目录 `index.html` 即可离线打开。全部样式、脚本、数据和已取得的头像均内嵌在文件中。

- 悬停头像查看背景，点击打开详细档案；键盘 Tab 也可打开背景浮层。
- 搜索使用真实姓名与已核对别名，例如“大老王”匹配王吉舟、“孙割”匹配孙宇晨。
- 职业标签可以同时选择多个，并与圈层组合筛选；“重置”恢复全部人物。
- 拖动年份轴进入历史视图，或输入精确日期。播放按年份推进。
- 已核实事件改变节点状态；主播评论和预测单独标注，不改变事实状态。
- 时期未明关系默认不进入历史视图，可以主动勾选显示。
- 主图下方的“关系变化”时间轴按日期更新连线；“上一变化 / 下一变化”跳到有日期依据的关系记录，不会自动切换人物。档案事件仍可点击“定位到这一天”。
- 手机端图谱内部左右滑动；点击人物后，画面会横向对齐圆心，详细档案在图谱下方。

## 维护

人物数据库：`../数据库/人物谱系.sqlite3`；照片与出处：`avatars/manifest.json`；页面模板：`template.html`。

先运行 `../数据库/export.py`，再运行 `build.py`。生成器以只读方式连接 SQLite。新增视频前必须完整阅读项目根目录《工作流.md》。系统 Python 若受 Xcode 许可限制，可用已有的 Codex bundled Python，不需要修改系统许可。

## 正圆聚焦版更新

全部人物沿同一正圆排列；点击人物后用约820毫秒缓动移动到圆心，关系线跟随。只显示当前人物的直接关系，无关人物以20%透明度保留；无关联人物会明确显示0位直接关联。返回全景恢复全部节点。尊重系统减少动态效果设置。

聚焦人物后，三层关系圈按直接关系类型排列：第一层为亲属和已有资料支持的亲密关系，第二层为业务往来，第三层为共事关系。争议、评论等无法归入这三类的直接关联留在外围，并在档案中列出。连线旁直接显示关系称谓；待核或单方说法以虚线和文字标记。没有已收录关系的节目提及人物不会被画成亲密关系。这个分层不表示亲疏强度，也不是旧版的亲属路径步数。

网页下方包含三种图形方案示意和原始互动案例链接；详细参考见《图形方案参考.md》。

## 多标签、圈层与视频证据

- 职业标签可多选，命中任一已选标签的人物就会显示；头像色环对应主标签，档案显示全部标签。
- “圈层归属”页用方框和树状分支表达人物所属圈子，虚线是待核实归属，可点击成员返回圆形主图。
- “视频依据”页可搜索56段本期细节，点击播放时间回看，下载完整原创分析Markdown。
- 人物档案上方展开“视频依据”可查看该人物的所有本期片段。播放秒数不是事件日期；事实时间轴独立控制。
- 普京、特朗普及4个仅观众身份账号已移出活跃库，相关历史行在备份／变更日志留存。
