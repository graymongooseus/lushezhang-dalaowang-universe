# Relationship graph 图形方案

这次采用“正圆总览 + 中心人物聚焦”：选择人物后移到圆心，其直接邻居清晰显示，其他人物以20%透明度保留并可继续点击。关系线只显示当前人物的直接关系。时间轴依旧决定关系是否在选定日期有效。

|方案|官方互动案例|适合的用途|限制|
|---|---|---|---|
|圆形捆绑连线|[D3 Hierarchical edge bundling](https://observablehq.github.io/notebook-kit/ex/d3/hierarchical-edge-bundling)|按群组组织密集关系，悬停区分连线方向|需要有依据的层级，不能把未知派系强行分组|
|邻居高亮|[Sigma.js use reducers](https://www.sigmajs.org/storybook/?path=/story/use-reducers--story)|单人关系探索、淡化无关节点|只是一度邻居，不代表完整社交网络|
|力导向布局|[D3 Force-directed graph](https://observablehq.com/@d3/force-directed-graph)|拖动节点观察网络聚集|距离是算法结果，不是现实好感分数|
|大型网络探索|[Sigma.js Wikipedia demo](https://www.sigmajs.org/demo/index.html)|未来人物规模更大时的搜索、漫游|更复杂的交互不应替代证据审查|

以上“适合的用途”为本项目设计判断；链接为原始案例，检索于2026-09-22。网页里的小图为原创结构示意，不是数据库证据或来源截图。
